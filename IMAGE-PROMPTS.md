# Pehra: 10 image prompts

Generate each image, save it with the **exact filename** shown, and drop it into
`~/sites/pehra/assets/images/`. The website already has a slot wired for every
filename. Until a file exists, the slot shows a labelled placeholder (or falls back
to your patio photo), so you can add images one at a time.

**Tips for consistency**
- If your image model accepts a reference image, attach your existing product photo
  (`assets/images/pehra-patio-dusk.jpg`) to every prompt so the trap looks identical.
- Generators often garble small text. If "PEHRA" comes out wrong on the body, fix it in
  an editor, or regenerate. Never ship a misspelled logo.
- Export as JPG at the sizes listed. Keep each file under ~400 KB (quality 80–85).
- The colour guide says: show the trap on Ivory or in a real scene, never on flat
  blue or flat black. The dark shots (03–05) use the allowed blue-to-Night glow.
